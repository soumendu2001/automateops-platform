
# 🚀 Ansible User Management CI/CD Project

This project demonstrates how to manage Linux users using:

✅ Ansible  
✅ Git-based configuration  
✅ CI/CD with GitHub Actions  

---

## 🧠 Concept

Git = Source of Truth  
Pipeline = Enforces State  
Servers = Always in Sync  

---

## 🔁 Workflow

1. Update users.yml  
2. Commit & push  
3. GitHub Actions triggers  
4. Ansible updates servers  

---

## 🔥 Features

- User lifecycle management  
- RBAC implementation  
- SSH key automation  
- CI/CD pipeline  
- Infrastructure as Code  

---

## 🎯 Use Cases

- DevOps automation  
- HR onboarding/offboarding  
- Security compliance  
- Access management
